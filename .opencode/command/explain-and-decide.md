Apply the three Explain and Decide mandates to the current task, and to this request if given: $ARGUMENTS. Mandate 1, zero-knowledge framing: write every question and explanation as if the reader knows nothing of the project, the subject or the work so far; define every term on first use, name things in words before identifiers, one idea per sentence. Mandate 2, a Pro and a Con on every option: whenever you present or weigh options, a plan or a recommendation, label at least one Pro and then one Con under each option, including the recommended one, the do-nothing option and both sides of a yes/no question; never proceed on an unanswered question. Mandate 3, ledger every decision: the moment a decision becomes final (the user chose, you chose alone without asking, or a meeting, email, thread or comment settled it), append it to LEDGER.md through the bundled ledger script, scripts/ledger.ts inside the installed explain-and-decide skill folder (${CLAUDE_SKILL_DIR} on Claude Code, else the install path of the skill, or skills/explain-and-decide in a checkout of this repository; the path is never relative to the current folder), run as node --experimental-strip-types followed by the full quoted script path, with -decision-human, -decision-agent or -decision-external, one decision per run, with the real options, their Pro and Con, the pick, the rationale and the consequences. Never edit LEDGER.md by hand, never commit, publish or quote it outside the user's session, and respect a .no-ledger marker.
