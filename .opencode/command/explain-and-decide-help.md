Show the Explain and Decide quick reference. One shot, change nothing: write no file and append nothing to the ledger. The three mandates: zero-knowledge framing (write every question and explanation for a reader who knows nothing of the project; define each term on first use), a Pro and then a Con on every option (including the recommended one and the do-nothing option), and a ledger entry for every final decision (appended to LEDGER.md through the bundled script, one decision per run). Ledger script: scripts/ledger.ts inside the installed explain-and-decide skill folder (${CLAUDE_SKILL_DIR} on Claude Code, else the install path of the skill, or skills/explain-and-decide in a checkout of this repository; the path is never relative to the current folder), run as node --experimental-strip-types followed by the full quoted script path; every Node.js release from 22.6 on accepts that flag. Switches: -decision-human, -decision-agent and -decision-external, each with an optional entry file, else the entry comes from standard input; -info prints the LEDGER.md path and size; -no-ledger disables the ledger by creating a .no-ledger marker; -yes-ledger removes it; -h or --help prints help. Decision append switches also accept --at datetime before or after an entry-file path. It sets Date to the supplied event time, using an ISO 8601 calendar datetime with an explicit time zone, such as 2026-10-28T09:00:00-07:00. Omit it to use script invocation time. The source on field is independent. Invalid dates or missing time zones exit 1 without writing; missing or repeated --at arguments and use with non-decision switches exit 2. Exit codes: 0 appended, 1 rejected with every problem listed and nothing written, 2 misuse or unreadable entry file, 3 ledger disabled, 4 LEDGER.md could not be written (locked by another program, read-only or full) and nothing recorded unless the line says written but not confirmed. Entry keys, one key: value per line: title, context, two or more opt each with pro and con, pick, why, plus, minus, optional status; by for human and agent decisions; deciders plus one source (url, or meeting + on, or subject + on + from, or other) for external decisions. LEDGER.md is private: the script lists it in .git/info/exclude so it never reaches a repository. Skills: /explain-and-decide (the mandates), /explain-and-decide-help (this card), /explain-and-decide-ledger (review LEDGER.md or record a decision by hand). Repository: https://github.com/Heretyc/explain-and-decide
