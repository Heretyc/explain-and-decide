description: Review the decision ledger (LEDGER.md) or record a decision by hand
---

Work with the project's decision ledger, LEDGER.md, as asked here: $ARGUMENTS. If no request is given, review it. First run the bundled script, scripts/ledger.ts inside the installed explain-and-decide skill folder (${CLAUDE_SKILL_DIR} on Claude Code, else the install path of the skill, or skills/explain-and-decide in a checkout of this repository; the path is never relative to the current folder), run as node --experimental-strip-types followed by the full quoted script path, with -info to find LEDGER.md and its state; say so plainly if the ledger is disabled or not created yet. To review: group entries by Status, surface Deprecated and Rejected first, show each decision with its chosen option plus the benefit and drawback that drove it, using natural sentences in review commentary; use Pro: and Con: labels by default in direct questions and formally recorded proposals, follow explicit project, environment or repository conventions unless the user requests otherwise, and preserve the format of quoted entries, quote its Context in plain language, and never paraphrase a decision without its Con. To record a decision: build an entry in the grammar (one key: value per line with title, context, two or more opt each with pro and con, pick, why, plus, minus, and the source keys), pick -decision-human, -decision-agent or -decision-external by who decided, deliver it by entry file or by standard input, and report the script's output verbatim. Decision append switches also accept --at datetime before or after an entry-file path. It sets Date to the supplied event time, using an ISO 8601 calendar datetime with an explicit time zone, such as 2026-10-28T09:00:00-07:00. Omit it to use script invocation time. The source on field is independent. Invalid dates or missing time zones exit 1 without writing; missing or repeated --at arguments and use with non-decision switches exit 2. A reversal is a new entry whose context names the entry it reverses, never an edit. Never edit LEDGER.md directly, never publish or quote it outside the user's session, and never remove a .no-ledger marker without being asked.
